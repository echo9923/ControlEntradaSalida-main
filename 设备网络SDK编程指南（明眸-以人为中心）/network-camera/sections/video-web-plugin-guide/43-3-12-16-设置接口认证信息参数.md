# 3.12.16 设置接口认证信息参数


功能说明

设置平台APPKey、APPSecret等信息。用于同时对接多个平台的场景，此时初始化中不能指定appkey、secret、ip、port 这些信息。

使用条件

初始化后使用。注：若已设置认证信息成功，在反初始化前，再次设置认证信息，且使用已有的 authUuid，则会失败报错。

功能标识：setAuthInfo
