# 3.12.1申请 RSA 公钥


功能说明

申请 RSA 公钥，用于对敏感信息（如 appkey、secret）加密。

使用条件

创建插件实例之后，销毁插件实例之前。使用完后如还需加密传输，建议重新申请公钥。

功能标识：getRSAPubKey
