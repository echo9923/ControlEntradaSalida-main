# Members


- `byEnable`：是否启用
- `byRes`：保留，置为0
- `struIPServer`：IPServer 地址
- `wPort`：IPServer 端口
- `wDvrNameLen`：DVR 名称长度
- `byDVRName`：DVR名称
- `wDVRSerialLen`：序列号长度
- `byRes1`：保留，置为0
- `byDVRSerialNumber`：DVR序列号
- `byUserName`：DVR 登陆用户名
- `byPassWord`：DVR 登陆密码
- `byChannel`：DVR 通道，参数值为通道号，例如byChannel=1表示通道1
- `byRes2`：保留，置为0
